# 2012 Individual Annuity Mortality Table and Projection Scale G2

Mortality rates and mortality improvement rates from the 2012 Individual
Annuity Mortality Basic (IAMB) Table and Projection Scale G2.

## Usage

``` r
qx_iamb

scale_g2
```

## Format

For the 2012 IAMB table, a data frame with 242 rows and 3 columns:

- age:

  Attained age

- qx:

  Mortality rate

- gender:

  Female or Male

For the Projection Scale G2 table, a data frame with 242 rows and 3
columns:

- age:

  Attained age

- mi:

  Mortality improvement rate

- gender:

  Female or Male
